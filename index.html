🚀 RepoLaunch Agent

Turning Any Codebase into Testable Sandbox Environment

## Introduction RepoLaunch is the **first** agentic SWE tool for repository build and test management across programming languages and operating systems. Given a code repository, RepoLaunch can: - Install all dependencies and build the repository, delivered as a docker image, with docker image layer info collected for Dockerfile reconstruction; - Organize the command to rebuild the repository inside a container after repo modifications; - Organize command to test the repository, write a parser to parse test output into structured testcase-status mapping, and optionally find per-testcase running command. RepoLaunch now supports: - All mainstram languages : C, C++, C#, Python, Java, Node.js (JS & TS), Go, Rust. - Building on linux images, android images, windows images. ## Applications RepoLaunch powers the build and test of the execution environments for the whole `SWE-bench-Live` Software Engineering Dataset Family. [GitHub](https://github.com/microsoft/SWE-bench-Live) [Leaderboard](https://swe-bench-live.github.io/) Now SWE-bench-Live datasets have been used by numerous organizations for benchmarking of LLMs and coding agents, and agentic training (Rejection-based SFT and Reinforcement Learning) of code Language Models. The SWE-bench-Live family now includes: - Python-only, Linux tasks: [SWE-bench-Live/SWE-bench-Live](https://huggingface.co/datasets/SWE-bench-Live/SWE-bench-Live) - Multi-lingual, Linux tasks: [SWE-bench-Live/MultiLang](https://huggingface.co/datasets/SWE-bench-Live/MultiLang) - Multi-lingual, Windows tasks: [SWE-bench-Live/Windows](https://huggingface.co/datasets/SWE-bench-Live/Windows) - Cross-platform Code Migration tasks: [SWE-bench-Live/OS-bench](https://huggingface.co/datasets/SWE-bench-Live/OS-bench) ## News **[20/Aug/2026]** Proposed the memory-aware solution to reuse existing successful results of RepoLaunch to build&test the different commits of the same repo.
